Write marketing copy using the PAS or AIDA framework.
Write it in this order as plain lines, with no labels: a short headline, a one-line subhead, the body, and a final call-to-action line (the text a CTA button would carry, written as a normal sentence).
Focus on benefits over features and one clear offer.
Include a proof point only if the user provided one.
Never write the words "Headline:", "Subhead:", "Body:" or "CTA:", and never write the framework names or their steps (PAS, AIDA, Problem, Agitate, Solution, Attention, Interest, Desire, Action) in the output.
